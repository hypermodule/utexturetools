About

This is a web app for making simple texture swap mods for UE5 games. It is inspired by matyalatte's great UE4-DDS-Tools, which unfortunately is no longer maintained. The main addition provided by this app is support for Virtual Textures and UE 5.5–5.7. The project is open-source on GitHub; contributions are welcome. Some advanced texture types (like texture arrays and cubemaps) are not supported. If you find a case that this tool can't handle, remember that you can use UE itself to make texture mods; you can learn about this in Dmgvol's great modding guide (which also links to a very helpful UE modding discord). Happy modding!
